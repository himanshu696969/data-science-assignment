# Data Science Assignment Portfolio

This repository contains my Data Science, Python, Git, GitHub, project-organization, and notebook exercises.

## Contents
- `theory_answers.md` — written answers for the theory tasks.
- `python_tasks.py` — API, Pandas, Matplotlib, and feature-engineering examples.
- `songs.csv` — sample music dataset.
- `processed_data.csv` — processed sample movie ratings.
- `helper_functions.py` — reusable Python functions.
- `analysis.ipynb` and `movie_ratings.ipynb` — sample Jupyter notebooks.
- `plot.png` — movie genre bar chart.
- `insta-analytics/` — data analytics project structure.
- `ml-project/` — Spotify popularity predictor project structure.
- `playlist.txt` and `playlist.md` — Git and branch exercises.
- `index.html` — simple GitHub Pages portfolio.
- `git_github_tasks.md` — commands and instructions for GitHub-only steps.

## Run the Python examples
Install Python 3, then run:

```bash
python -m pip install requests pandas matplotlib jupyter nbdime
python python_tasks.py
```

The API example requires internet access.

## Publish on GitHub
1. Create a repository on GitHub.
2. Copy these files into the repository.
3. Commit and push them.
4. To publish the portfolio, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. Add your own resume as `resume.pdf` before publishing; do not upload a resume containing information you do not want public.

## Important
This bundle prepares the files, sample data, and written answers. GitHub actions such as creating an Issue, forking a repository, opening a Pull Request, resolving a real merge conflict, and enabling Pages must still be performed on GitHub / your computer. Do not claim those actions are complete until you have done them.
